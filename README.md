# One Last Cast / 最后一竿

Official product, privacy and support pages for the offline iPhone/iPad fishing game by Xiaofan Jia.

- English product page: `index.html`
- 简体中文：`zh.html`
- Privacy: `privacy.html` / `privacy-zh.html`
- Support: `support.html` / `support-zh.html`

The website is static and uses no JavaScript, third-party analytics, advertising, external fonts or cookies added by the developer. Cover and fish illustrations are product artwork, not device screenshots. Game code, music, signing files and player data are not included.
